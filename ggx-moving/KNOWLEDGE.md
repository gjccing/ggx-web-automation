# GGX Moving — product knowledge (for agents)

> Auto-generated by the add-product skill. Update when UI or flows change.

## Overview

GoGoX Moving is a consumer-facing Next.js web app for booking moving and related services in Hong Kong. Users pick a service on the homepage, then complete a multi-step quote/booking form. No login is required. Form progress is stored in `sessionStorage`; orders are submitted to backend APIs that write to Google Sheets and optionally upload photos to Google Drive.

## Core flows

### 1. Standard moving quote (wizard)

Homepage → select **Standard moving** → **Estimate now** →

| Step | URL segment | Key fields |
|------|-------------|------------|
| 1 Move details | `move-details` | From / To addresses, date, time |
| 2 Items to move | `items-to-move` | Item picker list **or** free-text list |
| 3 Extra services | `extra-services` | Photos, moving boxes, optional add-ons |
| 4 Final details | `final-details` | Contact info, referral source, quote summary |
| 5 Submitted | `submitted` | Confirmation timeline |

### 2. Disposal only (wizard)

Same 4-step wizard as standard moving, but step 1 is `disposal-details` (From + date + time only — no To). Session key: `disposal-only`.

### 3. Corporate moving (single page)

Homepage → **Special moving services** → **Next** → `/{lang}/corporate-moving-services`

Fields: From/To (district + street), preferred date, contact name, phone, email, remarks, referral source → **Get an estimate for free** → `submitted`.

### 4. Overseas moving (single page)

Homepage → **Overseas moving** → **Next** → `/{lang}/overseas-moving`

Fields: From/To country selectors, preferred date, contact info, referral source → **Get an estimate for free** → `submitted`.

### 5. Van/truck rental (no movers)

Homepage → select card → **Next** → **Download App CTA dialog** (web only):

- Title: "Download GoGoX app to place your order"
- Body: move single items via app Transport → Move door-to-door
- Actions: **Download app** (link), **Got it** (close)

## UI conventions

- Mobile-first; content max-width ~650px centered on desktop
- **No `data-testid`** in repo — use `getByRole`, `getByLabel`, visible text
- Homepage footer CTA: **Estimate now** (std-moving) or **Next** (all other services)
- Service cards are clickable; selected card expands with image + pricing link
- Wizard: `ProgressStepper` (4 tabs), **Back** button, sticky footer with primary button
- Address/date/time use **button triggers** opening overlays, not inline inputs
- `Pricing and more info` opens external URL in new tab (from i18n `pricing_and_more_info_link`)
- Forms use `noValidate` with custom validation + error messages

## State & routing guards

- Wizard form data stored in `sessionStorage` under keys `std-moving`, `disposal-only`
- `usePreviousStepDataGuard` redirects to step 1 if steps 2–4 are accessed without `from`, `to`, `date`, `time` in session
- Direct URL navigation to later wizard steps will bounce back to `move-details`

## Known quirks (staging)

- Default move date = tomorrow (not today)
- Van/truck rental on web shows Download App dialog instead of in-browser flow
- Back button on wizard uses `history.back()` or `router.replace("/")` at entry point
- Google Tag Manager: `GTM-TZF63DC`
- Photo upload blob errors trigger `ImageOutdatedCTADialog` with retry/skip options
- Header hidden when embedded in GoGoX app WebView
